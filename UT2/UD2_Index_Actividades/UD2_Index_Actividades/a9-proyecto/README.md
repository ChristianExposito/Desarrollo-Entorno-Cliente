## UT2 - Fundamentos de JavaScript
En esta sección se ha implementado la lógica inicial de la aplicación utilizando exclusivamente los fundamentos de la UT2 (variables primitivas, cálculos, decisiones con `if` y `switch`, bucles `for`, plantillas literales y manipulación básica del DOM):
* Declaración de variables independientes para tres vehículos.
* Cálculos de precio medio y búsqueda del vehículo más caro.
* Elección de modelos mediante un menú con `switch`.
* Simulación de revisiones de mantenimiento mediante un bucle `for`.
* Volcado de datos estructurados en consola (`console.table`) y actualización dinámica del contenedor `#info` en la interfaz web.
